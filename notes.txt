How to Migrate (Step-by-Step)
Step A: Get your Connection String
Sign up for Neon.tech or Supabase.com

Create a new project/database.
Copy your Connection URI. It will look like this:
postgresql://user:password@ep-cool-darkness-123456.us-east-2.aws.neon.tech/neondb

Step B: Update your Reflex Config
Open your rxconfig.py file. You need to change the db_url from your local sqlite path to your new Postgres URL.

Step C: Install the Postgres Driver
Reflex needs a driver to talk to Postgres. Run this in your terminal:
pip install psycopg2-binary

Step D: Push your Schema
You don't need to manually "move" the SQLite file. Instead, you'll tell Reflex to build the tables in your new Postgres database:

Set your environment variable (Temporary for this step):
Windows: set DATABASE_URL=your_postgres_url_here
Mac/Linux: export DATABASE_URL=your_postgres_url_here

Run the migration:
reflex db init
reflex db migrate

to export file
reflex export

The "Easiest" Way: Reflex Cloud (Beta)
The creators of Reflex offer a hosting service specifically designed for their framework. It handles the frontend, backend, and the connection between them automatically.

How to do it: 1.  Create an account at cloud.reflex.dev.
2.  Install the Reflex CLI if you haven't updated recently: pip install reflex --upgrade.
3.  Run reflex login in your terminal.
4.  Run reflex deploy from your project folder.

Pros: Zero configuration; handles scaling; free tier available.
Cons: Currently in Beta; less control over the underlying server.



1. Update your rxconfig.py
import reflex as rx
import os
from dotenv import load_dotenv

# This loads the variables from a .env file (for local testing)
load_dotenv()

config = rx.Config(
    app_name="bom_audit_reflex",
    # 1. Get the URL from environment, or 2. Use local sqlite as backup
    db_url=os.getenv("DATABASE_URL", "sqlite:///reflex.db"),
    plugins=[
        rx.plugins.SitemapPlugin(),
        rx.plugins.TailwindV4Plugin(),
    ]
)

2. Create a .env file (Local Testing)
DATABASE_URL="postgresql://user:password@ep-your-project-id.neon.tech/neondb?sslmode=require"

3. Essential: Install the Postgres Driver
pip install psycopg2-binary python-dotenv

4. How to get the URL from Neon
Go to your Neon Dashboard.
On the right side, find the Connection Details widget.
Ensure the language is set to "Parameters" or "Connection String".
Copy the long URL that starts with postgresql://.

5. Deploying to Reflex Cloud
When you are ready to publish using reflex deploy:
The Reflex CLI will ask you for your environment variables.
Give it the name DATABASE_URL.
Paste your Neon string as the value.
